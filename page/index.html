# Manager
How these records are counted
  • Managers are tracked by their ESPN account, so records follow a person through team name changes.
  • Standings, averages, streaks, luck and bench points use regular-season games only. Ties count as half a win and end a streak.
  • Streaks carry over from one season into the next.
  • Playoff games are winners-bracket games between playoff seeds, including third- and fifth-place games. Consolation games are not counted.
  • Acquisitions are players added from waivers or free agency. Add/drops are adds plus drops. Trades count each trade a team made.
  • 2020 had a 4-team playoff. Every season since has had 6.
  • The data is a snapshot downloaded from ESPN. It updates only when it is downloaded again.
